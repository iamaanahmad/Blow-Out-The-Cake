# 🕯️ Blow Out The Cake

Built for the **Kiro Birthday Challenge**: one sentence in, a Kiro Spec out, a working app at the end.

## The one sentence

> Build a virtual birthday cake web app where blowing into your microphone snuffs out its candles one by one until a personalized confetti celebration and shareable card appear.

That sentence was handed to Kiro in **Spec mode**, which generated the full `requirements.md` → `design.md` → `tasks.md` chain checked into [`.kiro/specs/blow-out-cake/`](.kiro/specs/blow-out-cake/). That spec is committed unmodified as the first commit of this repo. Everything below was implemented by following its task list.

## What it does

1. **Setup** — enter a name, pick how many candles (1-12).
2. **Blow** — grant mic access and actually blow into your microphone. A simple volume/RMS analyzer on the Web Audio API detects the blow and snuffs one candle at a time, complete with a flicker-out and rising smoke wisp. No mic, or permission denied? A big **Blow!** button does the same job.
3. **Celebrate** — last candle out triggers full-screen confetti and a personalized birthday card with the name and today's date.
4. **Share** — download the card as a PNG, or use the native Web Share sheet on supported devices/browsers.

## Running locally

```bash
npm install
npm run dev
```

Then open the printed local URL. Allow microphone access when prompted for the full "blow" experience (works over `localhost`, and over `https` in production — browsers require a secure context for microphone access).

## Building for deployment

```bash
npm run build
```

Produces a static `dist/` folder — deployable to any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.). No backend or server runtime required.

## Testing

```bash
npm run test
```

Unit tests cover the state machine (setup → blowing → celebration → reset) and the fallback blow-button path. The live microphone flow, confetti, PNG export, and Web Share are verified manually since they depend on real browser hardware/APIs — see the manual checklist in [`.kiro/specs/blow-out-cake/design.md`](.kiro/specs/blow-out-cake/design.md#testing-strategy).
